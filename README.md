# Tool Suite landing page

A single static page (`index.html`) that showcases and links to my tools.

## Editing
- **Text, links, features:** edit the `SITE` and `TOOLS` config near the bottom of `index.html`.
- **Screenshots:** drop images into `screenshots/` (see `screenshots/README.md` for file names).
- **OneDrive link (Project Tracker):** in OneDrive, right-click the file → Share → *Copy link*
  (set to "People in your organization") and paste it as the tracker's `url`.

## Deploying
Hosted on Vercel and connected to this GitHub repo: every push redeploys automatically.
No build step — Vercel serves the files as-is.
